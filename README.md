# WebMentor AI

A responsive beginner-friendly website development learning dashboard.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in Replit or VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local preview URL.

## What's included
- Responsive SaaS dashboard and navigation
- Overview with progress and project cards
- Create-project modal with local React state
- Learning paths and lesson selection
- AI Mentor demo chat with sample teaching responses
- Settings screen

## Important
The AI Mentor currently uses demo responses. It is not connected to an AI provider. Authentication, cloud database, and real AI integration are intentionally left for later lessons.
